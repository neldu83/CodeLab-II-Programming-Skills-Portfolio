# Challenge 3 – Book Manager

## About the Program

This C++ program manages a small collection of books. The user can view all the books, search for a book using its ID, borrow a book and return it. The program also shows whether each book is available or borrowed.

## What I Used

I used a class called `Book` to store information such as the title, author, number of pages, book ID and borrowing status. I also used vectors, functions, loops and file handling to manage the books.

The program reads the book information from `bookData.txt` and saves any changes to the same file.

## Testing

I tested the program by viewing all ten books and searching for a book using its ID. I also tested borrowing and returning a book to check that its status changed correctly.

I restarted the program to make sure the information was saved.

## How to Run

Open `challenge3_books.cpp` in VS Code and compile it using a C++ compiler. Make sure `bookData.txt` is in the same folder before running the program in the terminal.
