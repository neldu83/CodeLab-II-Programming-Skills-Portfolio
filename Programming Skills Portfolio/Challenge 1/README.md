# Challenge 1 - CO2 Emissions Calculator

## About the Program

This C++ program calculates the estimated CO2 emissions from a car journey. The user enters the distance travelled in miles and selects either petrol or diesel. The program then calculates the emissions in kilograms.

## What I Used

I used functions, variables, if statements and while loops. I also added input validation to check that the user enters a valid distance and fuel type.

## Testing

I tested the program using petrol and diesel. I also tested negative numbers, letters and incorrect fuel types to make sure the program handles invalid inputs.

## How to Run

Open `challenge1_co2.cpp` in VS Code, compile the program using a C++ compiler and run it in the terminal.
